# Bundled interface fonts

Michroma (400) and Rajdhani (400, 500, 600, 700), Latin subsets, downloaded from Google Fonts on 2026-09-23. The build embeds the WOFF2 files in the userscript, eliminating runtime font requests. Original URLs and unicode ranges are in manifest.json. SIL Open Font License 1.1 notices accompany the fonts.
