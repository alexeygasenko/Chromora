Install Chromora

Three steps.
Then back to the canvas.

Chromora runs as a userscript on Wplace.live. No separate desktop app is required.

  1. 01

    Add a userscript manager

    Use a userscript manager such as Tampermonkey in your browser.

  2. 02

    Get the latest release

    Open Chromora’s latest release and install Chromora.user.js.

    Open latest release ↗
  3. 03

    Refresh Wplace

    Return to wplace.live, refresh the page, and open Chromora on the map.
