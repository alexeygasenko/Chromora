# Frutiger Aero typography

The theme uses **Exo 2** (600–700) for headings and **PT Sans** (400/700) for body text and controls. Latin and Cyrillic WOFF2 subsets are embedded in the userscript by the build; the Aero theme does not need a font CDN at runtime. Other characters use the declared system fallback.

Downloaded 2026-09-23 from the [Google Fonts CSS API](https://fonts.googleapis.com/css2?family=Exo+2:wght@600..700&family=PT+Sans:wght@400;700&display=swap). `manifest.json` records the exact source URL, weight, Unicode range and byte size for each unmodified font file.

Both families are distributed under the SIL Open Font License. The original license/copyright notices are included in `Exo2-OFL.txt` and `PTSans-OFL.txt`, from the [Exo 2](https://github.com/google/fonts/tree/main/ofl/exo2) and [PT Sans](https://github.com/google/fonts/tree/main/ofl/ptsans) directories of Google Fonts.
